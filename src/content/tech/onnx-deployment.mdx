## 为什么要做模型部署？

训练完的 `.pt` 文件无法直接上线。我们需要：

- **跨框架互操作**：ONNX 作为中间格式
- **高性能推理**：ONNX Runtime 利用 CPU/GPU 加速
- **版本一致性**：消除 Python 环境差异

## 导出 ONNX

```python
import torch

model = torch.load("resnet50.pt", map_location="cpu")
model.eval()

dummy = torch.randn(1, 3, 224, 224)
torch.onnx.export(
    model,
    dummy,
    "resnet50.onnx",
    input_names=["input"],
    output_names=["output"],
    dynamic_axes={"input": {0: "batch"}, "output": {0: "batch"}},
    opset_version=17,
)
```

## ONNX Runtime 推理

```python
import onnxruntime as ort
import numpy as np

sess = ort.InferenceSession("resnet50.onnx", providers=["CPUExecutionProvider"])
inputs = {sess.get_inputs()[0].name: np.random.randn(1, 3, 224, 224).astype(np.float32)}
outputs = sess.run(None, inputs)
print(outputs[0].shape)  # (1, 1000)
```

## 性能调优

- 启用 `GraphOptimizationLevel.ORT_ENABLE_ALL`
- 使用 `IoBinding` 做异步 GPU 传输
- 对于固定 batch 场景，关闭 dynamic axes

推理延迟可从 PyTorch 的 ~15ms 降至 ONNX Runtime 的 ~3ms（CPU）。
